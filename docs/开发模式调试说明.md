# 开发模式调试

准备 Go 1.22 或更新版本、Node.js 14 和 npm。从仓库根目录执行 `make build`，
然后在两个终端分别启动内存 Consul 和 Go API：

```bash
./bin/consulmock -addr 127.0.0.1:8500
```

```bash
consul_url=http://127.0.0.1:8500/v1 scheduler_disabled=1 ./bin/tensuns
```

在第三个终端运行 `make web-dev` 并打开 Vue CLI 输出的地址。`/api/` 默认代理到
`127.0.0.1:2026`，可用 `TENSUNS_API` 覆盖。运行 `make smoke` 可用独立的内存
Consul 样本验证 HTTP 兼容性。更多启动参数和故障排查见 [RUNBOOK](../RUNBOOK.md)。
